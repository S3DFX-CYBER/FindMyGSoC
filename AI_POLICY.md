Generative AI Contribution Policy

FindMyGSoC allows contributors to use Generative AI tools such as ChatGPT, Claude, Gemini, Copilot, and coding agents.

AI should be used as an assistive tool, not as a replacement for the contributor.

✅ AI-assisted contributions are welcome

You may use AI to:

- Understand the codebase or an issue
- Learn unfamiliar concepts
- Debug problems
- Suggest or improve code
- Write tests or documentation
- Improve grammar and communication

⚠️ What we don't want

Please do not submit contributions that are:

- Primarily generated by an AI or autonomous coding agent with little human involvement.
- Code you cannot explain or understand.
- Blindly copied from an AI without reviewing and testing it.
- Filled with unnecessary changes, boilerplate, or generic "AI slop".
- Submitted simply because an agent produced a working-looking PR.

If an AI agent made most of the changes, you are still responsible for understanding and validating them before opening the PR.

Maintainers may request changes or close a PR if the contributor cannot explain significant parts of their contribution or if the contribution creates unnecessary review burden.

🤝 The principle

«Use AI to help you contribute, not to contribute instead of you.»

We do not require disclosure for normal AI assistance. If AI generated a substantial portion of your contribution, voluntary disclosure in the PR is appreciated.
